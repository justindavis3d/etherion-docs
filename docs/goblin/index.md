# Goblin for Unity

Thank you for buying the **Goblin** character pack! Your support is what lets us keep improving our characters, fixing bugs and building new packs.

This documentation walks you through everything in the pack, from installing it and opening the demo scenes to building your own goblin camp with randomized looks and ragdoll deaths. Use the sidebar to jump to any page, or pick what you want to do below.

> [!info] Image placeholders
> Every image in this guide is a placeholder. The line under each one describes the screenshot to capture. Save the screenshots in an `images/` folder beside this file, using the file names shown.
